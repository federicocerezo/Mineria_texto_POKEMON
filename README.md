# Mineria_texto_POKEMON
Análisis completo de Pokémon de tipo eléctrico. Primero, scrapea datos de Pokémon y movimientos de Wikidex y PokeAPI. Luego, preprocesa los datos y entrena un modelo de NLP para clasificar los movimientos como ofensivos o defensivos. Finalmente, selecciona un equipo equilibrado de 6 Pokémon y muestra sus movimientos óptimos.
